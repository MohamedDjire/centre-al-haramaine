# Frontend — Centre Al Haramaine (Vite + React)

Stack : React (Vite), Tailwind CSS v4 (`@tailwindcss/vite`), React Router, Axios.

## Démarrage

```bash
npm install
copy .env.example .env
npm run dev
```

Configurer `VITE_API_URL` dans `.env` vers votre dossier `backend/api` sous XAMPP.

## Pages

- `/` — Accueil  
- `/a-propos` — Présentation  
- `/inscription` — Formulaire + fichiers  
- `/contact` — Coordonnées  
- `/admin` — Tableau des inscriptions (authentification admin)

Voir `INSTALLATION.md` à la racine du dépôt pour la base MySQL et le déploiement PHP.
